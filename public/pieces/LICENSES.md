# Piece set licences

Every set bundled here was checked for a licence that permits bundling in a
commercial web app (CC0, MIT, Apache 2.0, CC BY with credit). AGPL,
non-commercial (CC BY-NC*), "freeware"/"personal use" and unknown-licence sets
are never added. The SVG files are unmodified copies of the files Lichess
serves from `lichess-org/lila/public/piece/<set>/`, downloaded 2026-11-22.
Lichess records each set's author and licence in
<https://github.com/lichess-org/lila/blob/master/COPYING.md>; the upstream
licence was also checked at the source where one exists.
